# claude-split

**VPN только для Claude. Всё остальное — напрямую, с zapret.**

Windows-клиент, который отправляет через туннель **только трафик Claude** (десктоп-приложение и домены `claude.ai` / `anthropic.com`), а весь остальной интернет — YouTube, Discord, браузер, игры — оставляет напрямую, где его обрабатывает [zapret](https://github.com/Flowseal/zapret-discord-youtube).

Так Claude всегда выходит с одного зарубежного IP, а YouTube и Discord не страдают от VPN и не ломают туннель.

```
Claude ──► PAC-правило ──► xray (127.0.0.1:10809) ──► зарубежный сервер
Chrome / YouTube / Discord / всё остальное ──► DIRECT ──► zapret ──► интернет
```

---

## Возможности

| | |
|---|---|
| **Разделение трафика** | Через туннель идут только домены Claude. Остальное — напрямую |
| **Подписки** | Добавление, обновление, переключение и удаление подписок (VLESS-ссылки, base64) |
| **Ручные серверы** | VLESS-ссылка, SOCKS5 или HTTP-прокси — вручную, без подписки |
| **Фиксированный сервер** | Автопереключения нет: IP не скачет, выбор сохраняется между запусками |
| **Пинг серверов** | TCP-задержка по каждому узлу — без подключения и без смены IP |
| **Список сайтов** | Дополнительные домены, которые тоже идут через туннель |
| **Kill-switch** | Claude физически не может выйти в интернет мимо прокси. Встроенная проверка |
| **Zapret внутри** | Скачивается автоматически, обновляется с GitHub, пресеты подбираются по реальным проверкам |
| **Трей** | Сворачивается в трей и показывает статус цветом: зелёный / жёлтый / красный |

## Требования

- Windows 10 / 11 (x64)
- PowerShell 5.1 (встроен в Windows)
- Права администратора — **один раз**, для драйвера WinDivert (его использует zapret) и правил фаервола
- Любой VLESS/Reality-сервер, SOCKS5 или HTTP-прокси (подписка или одиночный сервер)

## Быстрый старт

1. Скачай репозиторий (Code → Download ZIP) и распакуй в любую папку.
2. Запусти **`Start.vbs`** — приложение стартует без окна консоли.
3. При первом запуске оно само скачает:
   - `xray.exe` — ядро туннеля (в `bin/`),
   - zapret — обход DPI для YouTube/Discord (в `zapret/`).
4. В окне добавь подписку или сервер:
   - тип **«Подписка»** — вставь ссылку и нажми «Добавить»;
   - либо тип **VLESS / SOCKS5 / HTTP** и ссылку на конкретный сервер.
5. Выбери сервер в списке → **«Подключить»**.
6. Claude Desktop запускай как обычно — он уже идёт через туннель.

`Run.cmd` делает то же самое, но через консоль (удобно для отладки).

## Как это работает

### 1. Только Claude через прокси

Приложение поднимает локальный xray с двумя входами: SOCKS5 `127.0.0.1:10808` и HTTP `127.0.0.1:10809`. В системные настройки Windows прописывается PAC-файл:

```js
if (host == "claude.ai" || host == "claude.com" || host == "anthropic.com") {
    return "PROXY 127.0.0.1:10809";
}
return "DIRECT";
```

Chrome и Claude Desktop (он на Chromium) читают этот PAC автоматически. Всё, что не Claude, идёт напрямую — поэтому zapret продолжает работать как обычно.

### 2. Kill-switch

Правила Windows Firewall блокируют `claude.exe` и его вспомогательные процессы на всех интерфейсах. Loopback-трафик Windows не фильтрует, поэтому соединение с локальным прокси `127.0.0.1` продолжает работать, а любая попытка выйти в интернет напрямую — отбрасывается.

Проверка («Claude» → «Проверить защиту») полностью локальная: правила, актуальность пути к `claude.exe`, отсутствие прямых соединений. Никаких запросов к Anthropic — проверить и не спалиться.

Важно: правила ищутся **по программе**, а не по названию, поэтому видны любые правила, блокирующие Claude (в том числе созданные раньше другой версией приложения).

### 3. Zapret

Zapret скачивается с [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и работает под управлением отдельного привилегированного демона (UAC нужен один раз за сессию).

- **«Применить»** — запускает выбранный пресет.
- **«Завершить»** — останавливает zapret. Кнопка показывается, только когда в списке выбран тот же пресет, что сейчас работает.
- **«Подобрать пресет»** — перебирает все пресеты и выбирает тот, где YouTube и Discord реально отвечают быстрее всего (3–4 минуты).
- **«Проверить обновление zapret»** — обновляет zapret и повторяет подбор.

Если выбранный пресет не поднялся, приложение пробует запасной и запоминает рабочий.

> Пресеты различаются по провайдерам: у кого-то работает `general.bat`, у кого-то только `general (ALT).bat`. Если YouTube не открывается — запустите «Подобрать пресет».

## Ограничения (честно)

- **Telegram** не читает системный PAC — ему нужно прописать прокси вручную: SOCKS5 `127.0.0.1:10808`, логин/пароль пустые.
- **Голосовые звонки** через VLESS-туннель обычно не работают: UDP не проксируется. Текст, медиа и каналы — работают.
- **Узлы xhttp/TLS** в списке появляются, но могут не подключаться — зависит от параметров сервера.
- **Автопереключения серверов нет** специально: скачущий IP раздражает антифрод Claude. Если сервер умер — выбери другой вручную.
- **YouTube без zapret** не заработает: DPI режет его напрямую. Туннель для YouTube не используется.

---

## Безопасность и приватность

- Подписки, ключи, логи и настройки **не** попадают в репозиторий — они лежат в `proxy/config.json`, `proxy/nodes.json` и игнорируются Git.
- Прокси слушает только `127.0.0.1` — снаружи недоступен.
- Полный выход из приложения (трей → «Остановить всё и выйти») гасит xray, zapret, PAC-сервер и убирает системный прокси.
- Автозапуск (если включён) стартует приложение скрыто в трей и показывает окно только если соединения нет.

**claude-split** is a Windows client that routes **only Claude traffic** through a VLESS/Reality (or SOCKS5/HTTP) tunnel, while everything else goes direct and is handled by [zapret](https://github.com/Flowseal/zapret-discord-youtube). It uses a PAC file so Chrome and the Claude desktop app pick up the proxy automatically, and a firewall kill-switch so Claude can never leak a direct connection.

Run `Start.vbs` — the first launch downloads xray and zapret automatically. Add a subscription or a single VLESS/SOCKS5/HTTP server, pick it, press connect.
